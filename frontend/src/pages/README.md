# THƯ MỤC TRANG GIAO DIỆN WEB (PAGES)
**Phụ trách code chính:** SV04 (Frontend Engineer)

Các màn hình cần phát triển theo tài liệu yêu cầu:
1. `Dashboard/`: Hiển thị chỉ số MTTR, MTBF, tổng số 300 máy, cảnh báo công việc quá hạn.
2. `Assets/`: Bảng danh sách 300 thiết bị, tìm kiếm theo mã, bộ lọc theo tình trạng, hiển thị modal chi tiết và sinh mã QR để in.
3. `WorkOrders/`: Bảng Kanban hoặc Danh sách phiếu công việc theo 5 trạng thái (OPEN, ASSIGNED, IN_PROGRESS, COMPLETED, CLOSED).
4. `Schedules/`: Xem lịch bảo dưỡng dự phòng theo tháng/tuần, cấu hình 3 kiểu lịch (Thời gian, Số giờ chạy, Ngưỡng cảnh báo).
5. `Parts/`: Bảng danh mục phụ tùng tồn kho, cảnh báo khi tồn kho dưới mức tối thiểu `minimum_stock`.
6. `Reports/`: Biểu đồ thống kê thiết bị hỏng nhiều nhất và phân tích lịch sử bảo trì.
